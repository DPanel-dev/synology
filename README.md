# DPanel 群晖套件

适用于 DSM 7.1（42661）及以上版本。

1. **下载**：到 [DPanel 主仓库 Releases](https://github.com/donknap/dpanel/releases) 下载 `.spk` 安装包。社区版选 `ce`，专业版选 `pe`；Intel 或 AMD 的 64 位机型选 `amd64`，64 位 ARM 机型选 `arm64`。例如，Intel 机型安装社区版选 `dpanel-ce-amd64.spk`。
2. **安装**：打开 DSM **套件中心 → 手动安装**，选择下载的 `.spk`，按向导完成设置。
3. **打开**：点击 DSM 中的 **DPanel** 图标。使用默认直连设置时，也可以在浏览器访问 `http://NAS地址:8086`；如果安装时改过端口，请使用实际端口。
